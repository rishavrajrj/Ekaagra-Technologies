# Competitor Intelligence & Local Market Monitoring Framework

## 1. Monitoring Philosophy: Gaps Over Copying

> [!CAUTION]
> **Never Copy Competitors**:
> Most regional competitors in North Bihar use generic template copy, unverified claims, or keyword-stuffed footers. Copying competitor tactics reproduces obsolete, low-trust search signals.
> 
> Instead, systematically evaluate: **"What critical information, speed, proof, or transparency are competitors failing to provide?"** — and engineer that into Ekaagra Technologies.

## 3. Local SERP Monitoring Methodology

When tracking core commercial queries (*"website developer Motihari"*, *"school ERP Motihari"*):

### Rules for Accurate Tracking:
1. **Never Rely on a Single Manual Search:** Google personalizes results based on previous search history, physical device GPS location, and browser cookies. A personal search from an office WiFi network does not reflect statewide rankings.
2. **Use Google Search Console (Primary Truth):** GSC records aggregate impressions and average positions across hundreds of real Indian searchers.
3. **Use Incognito / Clean Profile (Secondary Check):** When testing manually, open an Incognito window, clear location permissions, and set search region to India.
