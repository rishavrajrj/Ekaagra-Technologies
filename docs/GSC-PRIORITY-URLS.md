## Step-by-Step Instructions for the Site Owner

1. Log in to [Google Search Console](https://search.google.com/search-console).
2. Ensure you have selected the property: `ekaagratechnologies.site` (Domain) or `https://www.ekaagratechnologies.site/` (URL Prefix).
3. Paste the URL into the **"Inspect any URL in..."** top search box and press Enter.
4. Click **TEST LIVE URL** (wait 30–60 seconds while Googlebot fetches the page).
5. Verify that the test shows:
   - **URL is available to Google** (Green checkmark)
   - **Mobile Usability:** Page is usable on mobile
   - **Rich Results:** Detected valid schemas (`Breadcrumbs`, `Organization`, `Service`, `FAQ`, or `Article`)
6. Click **REQUEST INDEXING**.
7. Repeat for the next priority URL (Google Search Console permits up to 10–12 manual requests per day).
