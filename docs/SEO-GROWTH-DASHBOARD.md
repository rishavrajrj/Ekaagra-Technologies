# SEO Growth Intelligence & Commercial Measurement Dashboard

## 1. Governance Principle: Verified Telemetry vs Zero Assumptions

> [!IMPORTANT]
> **Data Integrity Policy**:
> Never invent, estimate, or fabricate numbers for search rankings, impression volumes, traffic, or client leads. If Google Search Console, GA4, or Google Business Profile data is not yet live or has insufficient searcher volume, record:
> **`Insufficient live data to make a ranking/conversion conclusion.`**
> All optimization actions must be driven by verified telemetry, not speculation.

## 3. Search Query Classification Engine

When real Search Console query data is exported, classify queries into these 5 distinct intent buckets to evaluate cluster health:

```text
                                SEARCH QUERIES
                                      │
         ┌───────────────┬────────────┼────────────┬───────────────┐
         ▼               ▼            ▼            ▼               ▼
     [BRAND]         [WEBSITE]    [SOFTWARE]    [SCHOOL]     [INFORMATIONAL]
```

### Bucket 1: Brand Queries
- **Queries:** `Ekaagra Technologies`, `Ekaagra`, `Ekaagra Technologies Motihari`, `Ekaagra web studio`
- **Search Intent:** Navigational
- **Primary Landing Page:** `https://www.ekaagratechnologies.site/`
- **Expected Benchmark:** Position 1.0, CTR > 40%

### Bucket 2: Local Commercial Website Queries
- **Queries:** `website developer Motihari`, `website development Motihari`, `web designer Motihari`, `web development company Motihari`, `website design Motihari Bihar`
- **Search Intent:** Commercial Local
- **Primary Landing Page:** `/website-development-motihari`
- **Expected Benchmark:** Target positions 1–3 in East Champaran

### Bucket 3: Custom Software & Web Applications
- **Queries:** `software development Motihari`, `custom software Motihari`, `web application development Motihari`, `billing software Motihari`
- **Search Intent:** Commercial Software
- **Primary Landing Pages:** `/software-development-motihari`, `/web-application-development-motihari`
- **Expected Benchmark:** Positions 1–5 across North Bihar

### Bucket 4: Educational Technology & School Systems
- **Queries:** `school website Motihari`, `school website developer Bihar`, `school ERP Motihari`, `school ERP Bihar`, `CBSE school website design`
- **Search Intent:** Institutional Commercial
- **Primary Landing Pages:** `/school-website-development-motihari`, `/school-erp-motihari`
- **Expected Benchmark:** Dominant authority across Motihari, Bettiah, and Muzaffarpur

### Bucket 5: Informational & Evaluative Queries
- **Queries:** `website development cost in Motihari`, `school ERP vs school website`, `how to choose best website developer`, `CBSE mandatory disclosure checklist`
- **Search Intent:** Educational / Evaluative
- **Primary Landing Pages:** `/blog/*` articles
- **Expected Benchmark:** Featured snippets & high click-through to pricing funnels
