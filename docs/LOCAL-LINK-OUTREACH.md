# White-Hat Local Authority & Editorial Link Outreach Playbook

## 1. Principles of Natural Authority Building

Google’s Spam Policies explicitly devalue automated, paid, or manipulative link schemes. In local search for professional services, **relevance and authenticity outweigh link volume**.

### 🚫 Prohibited Practices
- Never purchase links from Fiverr, freelance networks, or automated syndication tools.
- Never use Private Blog Networks (PBNs) or link exchange groups.
- Never post spam comments on unrelated blogs or forums.
- Never build links with exact-match keyword anchors (e.g. avoid *"best website developer in Motihari"* as link text).

### ✅ Legitimate Link Building
- Naturally earned editorial links from real clients, educational partners, and regional business directories.
- Branded anchor text (*"Ekaagra Technologies"* or *"Website by Ekaagra Technologies"*).

## 2. High-Impact Outreach Channels

### Channel 1: Client Website Footer Attribution (Highest Impact)

When completing a website for a client, request permission to include a discreet, tasteful attribution credit in their footer.

#### Client Attribution HTML Template:
```html
<p class="text-xs text-gray-500">
  Website by 
  <a 
    href="https://www.ekaagratechnologies.site/" 
    target="_blank" 
    rel="noopener"
    class="hover:text-indigo-600 transition-colors"
  >
    Ekaagra Technologies
  </a>
</p>
```

#### Guidelines:
- Always obtain client consent during the project handover phase.
- Ensure the link is clean, visible, and uses the canonical URL `https://www.ekaagratechnologies.site/`.
- Never hide links or style them in transparent colors.

---

### Channel 2: Educational Institution Partnerships

Educational websites in Bihar carry substantial domain trust.
- **Offer:** Partner with local schools or institutes (like Roshani Public School or coaching academies) to publish official annual academic calendar templates or digital safety guidance.
- **Attribution:** The institution credits Ekaagra Technologies as their official digital infrastructure and website technology partner.

---

### Channel 3: Regional Trade & Business Associations

- Register with regional commerce forums and merchant networks in East Champaran and North Bihar.
- Obtain verified member directory listings that include the studio's website URL.

---

### Channel 4: Open-Source Software & GitHub Authority

- Publish developer utilities, Next.js starter components, or CBSE disclosure schemas on GitHub.
- Developer community references, documentation citations, and GitHub repository links build legitimate technical authority.
