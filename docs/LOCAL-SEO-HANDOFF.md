## 4. White-Hat Backlink & Attribution Rules

- **Client Project Attribution:** When delivering a website, request client consent to place a clean, discreet footer link:
  ```html
  <p>Website by <a href="https://www.ekaagratechnologies.site/">Ekaagra Technologies</a></p>
  ```
- **Relevance Over Volume:** A single legitimate backlink from an active school portal, a regional merchant association, or a GitHub open-source project provides more domain trust than 500 low-quality forum profile links.
- **Strictly Prohibited:**
  - Private Blog Networks (PBNs)
  - Bulk directory submission services
  - Automated backlink blasting software
  - Paid links or blog comment spam
